# banger

Banger（バンガー）は、AIで作るHTMLの「めくらない」プレゼンテーションの、OSSライブラリと配信プラットフォーム（banger.page）です。このデザインシステムは、banger.page などのWebを作るときの基準です。

名前の由来：スライド＝すべる → スライドショーしない＝すべらない → 絶対にウケる＝banger。

## 基本の考え方

- **土台は墨と生成り、アクセントは1色。** 色で賑やかにせず、停止点の赤橙（`signal`）1点だけで目を引きます。1つの画面で `signal` を使う要素は原則1つです。
- **線で区切り、影は使わない。** カードやパネルは `line` の1pxの線で区切ります。影はトークンに定義していません。
- **形は「16:9の画面」と「点」。** ロゴのお腹（カウンター）は16:9、中の点は停止点です。図形やUIのアクセントも、この2つから作ります。
- **大きく言い切る。** 見出しは Bricolage Grotesque の極太で大きく、本文は日本語の読みやすさを優先して行間を広めに取ります。

## 言葉づかい

- 正式名称は大文字始まりの「Banger」、読みは「バンガー」です。文章の中ではこの表記にします。小文字の `banger` は、ロゴのワードマーク・パッケージ名（`@bangerpage/core`）・コマンド名・ドメイン（banger.page）だけで使います。
- 短く言い切ります。「〜することができます」ではなく「〜できます」。
- 機能の説明より、できるようになることを書きます（例：「停止点ごとにPDFへ書き出せる」）。
- 遊び心は名前とキャッチコピーに任せ、UIの文言はまじめに書きます。絵文字は使いません。
- 「スライド」という言葉はなるべく避け、「発表」「停止点」「キャンバス」を使います。
- 例：見出し「めくらないプレゼン」、リード「AIと話して、HTMLで作って、PDFでも配れる。」、クレジット「presentation generated by banger」。

## ロゴ

ロゴはアイコン（b のモノグラム）と文字（ワードマーク）の組み合わせです。素材は Logos グループにあります。

- **アイコンの構造**（64×64のグリッド）：縦の線は11、横の線は9（横線が太って見えるのを補正）。カウンターは30×17でほぼ16:9。停止点は直径9でカウンターの中心。外角R12、内角R3。
- **ワードマーク**：Bricolage Grotesque 800、opsz 96、小文字の `banger`。字間は1文字ずつ調整します（右側の余白、em単位）：b −0.035 / a −0.015 / n −0.02 / g −0.03 / e −0.045。文字のアウトライン化はまだしていないので、当面はこの設定のテキストで組みます。
- **組み方**：アイコンの下端を文字のベースラインにそろえ、アイコンの高さは文字のアセンダー（b の高さ）と同じにします。アイコンと文字の間は、アイコンの縦線2本分です。
- **余白**：ロゴの周囲には、アイコンの縦線2本分以上の余白を空けます。
- **最小サイズ**：アイコン単体は16px、アイコン＋文字は横幅80px。
- **色**：明るい地では墨の字形＋`signal` の点、暗い地では生成りの字形＋`signal` の点。アプリアイコンは `signal` の地に白の字形と墨の点です。
- **単独で見せるときはアプリアイコン**：アイコンが文字を伴わずに単独で出る場所（SNS・GitHub・npm のアバター、favicon、OGP画像、トークの表紙、ストアのアイコン）では、`signal` の地のアプリアイコンを使います。地の赤橙が Banger の色として覚えられるようにするためで、暗い地に白い文字と赤橙の点を置く形は、ほかのサービスのロゴと見分けにくくなります。墨や生成りの字形のアイコンは、ワードマークと組むときと、文書や UI の中で小さく添えるときだけに使います。
- **してはいけないこと**：字形の変形・回転、点の色を2色以上にする、影や縁取りやグラデーションを付ける、写真の上に直接置く、`signal` の地に `signal` の点を置く。

## 色

テーマは2つです。**Signal**（ライト、標準）と **Signal Dark**（ダーク）で、どちらも `paper` / `surface` / `ink` / `ink-muted` / `signal` の組み合わせでできています。

- 本文は `ink`、補足は `ink-muted`。どちらも両テーマで 4.5:1 以上です。
- `signal` は塗り専用です。その上の文字は必ず `on-signal`（墨）にします。白い文字は 3:1 程度で基準を満たしません。
- リンクや強調の文字色は `signal-text` を使います。`signal` そのものは生成りの地では文字に使えません。
- 区切り線は `line`、入力欄などの枠は `line-strong`（3:1以上）。
- **Lime Night（キャンペーン用）**：`lime` は告知、Product Hunt、トークのキービジュアルだけに使い、地は必ず墨（#141414）にします。`signal` と同じ画面には置きません。プロダクトのUIには使いません。

## 文字

- **見出し・ロゴ**：Bricolage Grotesque（`display`）。ラテン文字だけなので、日本語は Noto Sans JP に切り替わります。日本語の見出しも同じ太さ（800）で組みます。
- **本文**：Noto Sans JP（`sans`）。行間は1.8前後と広めにします。
- **コード**：JetBrains Mono（`mono`）。タグ名、CLIのコマンド、コード例に使います。
- 3書体ともGoogle Fontsから読み込みます（`display` は opsz,wght@12..96,800、`sans` は 400;700、`mono` は 400）。

## レイアウト

- 余白は `space-*` の段階だけを使います。カードの内側は `space-6`、セクション間は `space-16`。
- 角丸は、入力欄が `radius-s`、ボタンが `radius-m`、カードが `radius-l`、アプリアイコンが `radius-icon`。
- プレゼンの埋め込み枠は16:9、角丸 `radius-l`、`line` の枠線で表示します。
- フォーカスは `focus` 色の2pxのアウトラインに2pxのオフセット。

## アイコン

- 線のアイコンで、線幅は1.75px、角と端は丸めます（Lucide に近い描き方）。
- 色は `ink` か `ink-muted`。`signal` のアイコンは、その画面で一番大事な1つだけです。

## 読み込み中

- ボタンを押した後の待ちや、AIの生成・書き出し・公開を待つ表示には、b が動く `Loader`（M1〜M5）を使います。標準は M1 Pulse です。
- 400ms未満の待ちには出さず、出したら最低600msは表示します。何を待っているかを短い言葉で添えます。
- 動きを減らす設定では、停止点がゆっくり明滅するだけになります。

## Webでの使い方

- トークンの正本は `tokens.json` です。Webではここから CSS 変数（`--signal` など）を作って読み込み、`<html data-theme="light">`（または `dark`）でテーマを切り替えます。発表のランタイム（`@bangerpage/core`）は、同じトークンから `--bang-` で始まる変数を生成して使います。OSの設定に合わせる場合は、`prefers-color-scheme` で `data-theme` を切り替えます。
- 色や寸法は値を直接書かず、`var(--signal)`、`var(--space-6)` のようにトークンで参照します。
- favicon は `banger-favicon.svg`、OGP画像やアプリアイコンは `banger-app-icon.svg` を使います。
