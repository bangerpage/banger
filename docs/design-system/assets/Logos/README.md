# Logos

banger のロゴ素材です。すべてSVGで、色は固定です（`currentColor` は使っていません）。

- **banger-mark.svg**：アイコン単体。明るい地用（字形 #141414、点 #FF4A1C）。
- **banger-mark-reverse.svg**：アイコン単体。暗い地用（字形 #F6F5F1、点 #FF4A1C）。
- **banger-app-icon.svg**：アプリアイコン・OGP用。地 #FF4A1C、字形 #FFFFFF、点 #141414、角丸22%。
- **banger-app-icon-lime.svg**：キャンペーン用（Lime Night）。地 #C6F432、字形と点 #141414。告知やProduct Huntだけで使います。
- **banger-favicon.svg**：favicon用（32×32）。小さいサイズで潰れないよう、点を少し大きくしています。

ワードマーク（文字部分）はまだアウトライン化していません。組み方は README のロゴの節を参照してください。
